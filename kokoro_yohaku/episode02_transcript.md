# 心に余白を。第2回

**正しいことを言っているのに伝わらない**

長男を理解する、私を守る育児ラジオ

## 1. 正しいのに、届かない

夕方、子どもが算数の問題を解いています。途中の式を見て、親は気づきます。あ、そこ、計算が違う。ここで直せば、次は間違えずに済むかもしれない。そう思って「その式、もう一度見て」と言った瞬間、「分かってる！　うるさい！」。え、間違いを教えただけなのに。こちらは時間を使って手伝っているのに。そんなふうに、心がざわつくことはありませんか。
こんにちは。「心に余白を。」です。第２回は、「正しいことを言っているのに伝わらない」。
今日の話は、親の言うことが間違っている、という話ではありません。正しい言葉と、伝わる言葉の間には、ときどき小さな橋が必要だというお話です。
そして、その橋を作るために、今日覚える方法は一つだけ。「一度に一つ、具体的に伝える」。何もかも説明しなくても、話が進む場合があるんです。

## 2. 『分かる』と『今できる』は違う

まず、子どもから「分かってる」と言われた場面を、少し別の角度から見てみます。
頭の中には、いま計算している数字、途中の手順、次に書こうとしていること。いくつもの情報が並んでいるかもしれません。そこへ横から、「この式が違うよ。まずここを直して、次に問題文を読み直して、そもそも前にも言ったけど」と説明が入る。子どもには、まだ処理していない言葉が次々届くことになります。
心理学には、作業記憶、ワーキングメモリーという言葉があります。情報を短い間、頭の中に置きながら使う働きです。その容量や使い方には個人差があり、目の前の課題が難しいほど、追加の説明を受け取る余裕が減ることがあります。
ADHDの特性がある場合、注意の配分や切り替えが課題になることもあります。学習面の苦手さが重なれば、指摘が負担になりやすい場合もあります。でも、これは全員に当てはまる説明ではありません。単に一人で解きたかったのかもしれませんし、親の言い方が嫌だったのかもしれません。見ただけで理由は決められないんです。
もう一つ、思春期ならではの視点もあります。自分でやりたい。失敗しても、まずは自分の力で試したい。そんな気持ちです。親が間違いをすぐ直すと、子どもにとっては、答えだけでなく、考える順番まで奪われたように感じる可能性があります。
一方で、親にも理由があります。時間は限られている。あとで覚え直すのは大変。今のうちに分かるようにしてあげたい。そう思うのは、自然なことです。
つまり、ここで対立しているのは、「勉強が大切」という考えと、「勉強なんてどうでもいい」という考えだけではないかもしれません。教えたいタイミングと、自分で考えたいタイミングのずれ。そのずれが、言い合いを大きくしている場合もあるんです。
前回は、感情が高ぶったら会話をいったん保留する、とお話ししました。今日は、その一歩手前。まだ落ち着いて話せるときに、どう伝えるかを考えます。

## 3. 今日の技術『一度に一つ』

では、具体的な場面で比べてみましょう。
親の頭の中には、言いたいことが三つあります。計算の符号が違う。途中式はもっと丁寧に書いてほしい。そもそも問題を最後まで読んでほしい。
よくある言い方は、こんな感じです。「ここマイナスじゃない？　それに途中式が雑だし、問題をちゃんと読んでないよね。だからいつも間違えるんだよ」。
親は改善点を三つ伝えたつもりでも、子どもには「全部だめだ」と聞こえるかもしれません。
そこで、今日の方法。「一度に一つ、具体的に伝える」です。
たとえば、子どもの手が止まって、こちらを見たときに。「一つだけ確認していい？　このマイナスの記号を見てみて」。
ここまで言ったら、いったん黙ります。説明を続ける代わりに、子どもが式を見直す時間を渡すんです。
もし子どもが「いま自分でやる」と答えたなら、安全に関わることでなければ、「分かった。必要なら呼んでね」と引ける場面もあります。教えないことと、見捨てることは同じではありません。
ただし、「一つだけ確認していい？」と聞いたからといって、必ず話を聞いてくれるわけではありません。本人の気持ちや、課題の難しさによっては、返事がない日もあります。そんなときまで、何度も確認を迫らなくていいんです。
ピアノでも考えてみましょう。「そこ音が違う、もっとゆっくり、指も気をつけて、昨日もそうだった」と重ねる代わりに、「最後の二小節だけ、もう一度弾いてみる？」。
ただし、これは一つの提案です。本人が望んでいないときには、無理に練習指導を続ける必要はありません。練習の量や、誰がどこまで関わるかは、落ち着いた別の時間に家族で決められます。
ここで重要なのは、短く言うこと自体が目的ではない、という点です。行動が具体的で、今何をすればよいのか分かること。これがポイントです。
「ちゃんとしなさい」は短い言葉ですが、何をすればいいかは分かりません。「この一行を見てみて」は、やることが見える言葉です。
もし説明を聞いたあと、子どもが一つのことを実行できたら、「マイナスに気づいたね」と事実を伝えてもいいでしょう。大げさな褒め方は不要です。
そして、これも大切です。学習がうまく進まない原因は、指示の長さだけではありません。内容が難しすぎる、疲れている、学習量が多い、そもそも本人がその方法に納得していない。そんなときには、指示を磨くより、課題の量や環境、支援の分担を見直す方が役立つこともあります。
怒鳴り声や暴力が始まったら、その場の指導は止め、安全を優先します。落ち着くまで待つことを、親の負けだと思わなくていいんです。

## 4. 『今言わなきゃ』から自由になる

ここからは、親の気持ちの話です。
勉強を見ていて間違いに気づくと、すぐ直してあげたくなります。今、修正できなかったら。このまま覚えてしまったら。次のテストでまた間違えたら。そんな心配が、次々に頭をよぎることがあります。
認知行動療法では、頭に浮かんだ考えを、いったん言葉にして眺める工夫があります。たとえば、「今すぐ全部教えなければ、この子は困る」。これが浮かんだとき、「本当に、今この瞬間でないといけないだろうか」と問い直してみる。
もちろん、今伝えた方がよいこともあります。でも、一つの間違いを今日中に全部直さなくても、学ぶ機会がなくなるわけではありません。後日、先生や別の家族に頼る方法もあります。
気になるところを全部見つけて、全部教えて、全部身につけさせる。これを一人で担うのは、とても重い仕事です。
親が指導役から少し離れて、応援する役に回る。好きな歴史の話を一緒に楽しむ。子どもが興味のある本を、ただ面白がって聴く。そんな時間も、親子の関係を支える一部です。
「今日は、この一つだけ伝えられた」。あるいは、「今日は教えるのをやめられた」。どちらも、状況に合わせた選択になり得ます。
親が疲れている日には、教え方を工夫するより、教える量そのものを減らしていい。これは、手を抜くこととは違います。続けられる関わり方を選ぶということです。

## 5. 今日の一言と、次回予告

今日の小さな実践は、一つだけ。
何かを直してほしいとき、「一度に一つ、具体的に伝える」。たとえば、「このマイナスの記号を見てみて」。そして、そのあと一拍、待ちます。
一度で伝わらなくても、何かを証明する必要はありません。伝わりにくい日は、また別のやり方を考えればいいんです。
今日のまとめです。正しいことを、全部いっぺんに言わなくていい。言葉を減らすことは、関心を減らすことではありません。
次回のテーマは、「暴言を吐かれたとき、親はどうする？」。気持ちは理解しても、傷つける言葉や行動を許さない。そのための境界線を、具体的に考えます。
「心に余白を。」、また次回。どうぞ、今日のあなた自身の時間も、大切にしてください。
