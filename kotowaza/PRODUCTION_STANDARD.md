# ことわざ事件簿｜聴く力を引き出すシリーズ制作基準 v2
作成日: 2026-10-28
基準: 「ことば幻獣ラジオ」第1回の推理・心情・文脈学習の品質を参考に、ことわざ検定9級の学習内容に合わせて調整する。

## 番組の目的
1. ことわざ・慣用句を、説明の丸暗記ではなく人の行動・証言・気持ちの中で理解する。
2. 話の続きを聴かなければ事件を解けない構成にして、注意深い聴き取りを引き出す。
3. 小4にはわかりやすく、小6にも推理・判断・気持ちの読み取りを楽しめる内容とする。
4. 最初から登場語句の意味を列挙せず、少し考えれば文脈から推測できる場面を作る。
5. 各回に対応するA4復習プリントを1枚用意できるよう、ヒント・推理・言葉の使い方を設問化する。

## 元データの扱い
- ユーザー提出の「ことわざ・慣用句 意味と例文一覧」（226語）を参照する。書籍原文の全件照合未実施であることを忘れない。
- 「口を捕える」「首をはさむ」は表記・意味の確定前に出題しない。
- 1回6〜8語を目安にし、意味の正確さと自然な用例を優先する。
- 使う語句は全文内に2回以上自然に登場させ、必要なら同じ場面で連呼せず別場面にする。

## 物語・脚本
- 冒頭30〜60秒以内に事件を提示し、最後まで聴きたくなる問いを示す。
- 登場人物の性格に応じた掛け合い、意見の違い、誤解、気持ちの変化を入れる。
- 「ことわざが物理的に起こる」という同じギャグの連続を避ける。
- 犯人当てよりも証拠と推測を区別すること、証言者を決めつけずに事情を聞くことを重視する。
- 大事な手がかりは先に提示し、あと出しで解決しない。
- 少なくとも1回は、中盤で現在わかっている事実を短く再確認する。
- 事件の解決が、取り上げた言葉の意味とつながるようにする。
- 意味の解説は「自然な使用 → 文脈から推理 → 短い説明 → 異なる場面で再使用」の順を基本とする。
- 小4が耳だけで追えるよう、一度に提示する手がかりや登場人物を増やしすぎない。

## 参加型の考える時間
- 物語の中に本当の推理問題を1〜3回設置する。正解の直前に4〜7秒の無音または小さなカウント音を置く。
- 最後に5〜7問の言葉の応用・理由説明・場面判断クイズを入れる。
- 明らかすぎる二択や同じ意味の反復だけで終わらせない。
- 誤答を笑いものにしない。正解の根拠を簡潔に説明する。
- ラジオを聴く子どもに「いまわかったことは？」「何がまだわからない？」と考える理由を与える。

## 音声・公開
- VOICEVOXの複数声、抑えめのオリジナルBGM・場面転換ジングル・効果音を利用する。
- 10〜15分程度。ただし尺稼ぎよりテンポを優先する。
- まいにちニュースや旧ことわざラジオのファイルを変更しない。
- 音声ファイル名とGitHub Releaseタグは毎回一意にし、MP3存在・秒数・音声生成ログ・Release公開を確かめる。
- 現状GitHub Pagesは使えないため、成功しているGitHub ReleasesのMP3リンクを優先。
- 実機Androidで試聴していない場合は、その旨を正確に伝える。

## 監修のチェックリスト
- 子どもが初めて耳だけで聴いて状況を追えるか。
- 冒頭に引きがあり、途中で注意が離れても戻れるか。
- 登場人物の行動や気持ちに不自然な点がないか。
- 語句の意味と使い方に誤りがないか。
- 途中の謎が推理可能で、答えが後出しでないか。
- 4〜7秒の回答待機が実際のMP3に含まれるか。
- BGM・発音・音量・会話の速さは子どもの理解を邪魔しないか。
- A4復習プリントが物語の理解と語句の定着の両方を測れるか。
